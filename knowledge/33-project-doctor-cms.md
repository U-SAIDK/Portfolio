Doctor CMS is a custom healthcare content management system that Usaid led as Lead Engineer at Data Innovations Technologies. It gave the organization complete control over its website content and structure without relying on WordPress or any third-party CMS.

Highlights: centralized website content management; database-backed persistent content with real-time website updates; built from the ground up with Next.js, React and TypeScript; Node.js backend with JWT-based authentication and secure APIs; designed for flexible content updates while keeping application control and consistency.

Tech stack: Next.js, React, TypeScript, Node.js, JWT.
