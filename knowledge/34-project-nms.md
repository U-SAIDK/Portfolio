NMS (Nursery Management System) is an end-to-end nursery management platform spanning a web application, backend services and mobile apps, designed to centralize nursery operations with dedicated web and mobile experiences. Usaid contributed across the whole stack.

Highlights: a modern web application built with Next.js, React and TypeScript; Spring and Spring Boot backend services for the core business workflows; React Native apps for both Android and iOS; native Kotlin and Swift integrations for platform-specific capabilities such as the camera.

Tech stack: Next.js, React, TypeScript, Spring Boot, React Native, Kotlin, Swift.
