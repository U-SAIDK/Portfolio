Usaid Khan is a Software Engineer based in Pune, Maharashtra, India. He works as a Software Development Engineer at Data Innovations Technologies Pvt. Ltd., where he has been full-time since April 2025 after joining as an intern in August 2024.

He describes himself as a full-stack engineer, DevOps practitioner and cloud-native enthusiast: comfortable from pixel-level web interfaces down to distributed systems running on Kubernetes. His day-to-day work centres on Java and Spring Boot microservices, React and Next.js front ends, Docker and Kubernetes, CI/CD pipelines and GitOps.
