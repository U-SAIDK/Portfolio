For Handshake AI's Project Dynamo, Usaid designed and validated a deterministic AI-coding benchmark: forensic recovery of a corrupted content-addressed backup store. The task covers chunk-map reconstruction, content-defined-chunking parameter inference, snapshot/pack chronology recovery and historical-forgery detection.

He built the Docker/Harbor task environment, the verifier and the oracle solution (validated at reward 1.0 against a 0.0 no-op baseline), and debugged GitHub Actions CI and AI-agent evaluation timeout behaviour.
