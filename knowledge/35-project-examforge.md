ExamForge (HI Tech Examination) is a self-hosted, secure MCQ examination platform that Usaid built as a full-stack developer using Next.js, TypeScript, PostgreSQL and Prisma.

Highlights: JWT authentication, access control, exam scheduling and secure session management; exam-security features including full-screen enforcement, tab-switch detection, time limits and auto-submit; admin analytics, submission management, audit logging and SMTP email notifications.

Tech stack: Next.js, TypeScript, PostgreSQL, Prisma, Tailwind CSS, JWT.
