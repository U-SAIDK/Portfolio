TherapyCRM.io is a healthcare CRM platform that powers workflows for therapy practices. Usaid contributed as a full-stack engineer across secure backend services, APIs, authentication, database operations and infrastructure.

Highlights: 50+ business endpoints with standardized API responses; JWT authentication, Spring Security and role-based access control; PostgreSQL optimization that reduced query times by up to 40%; microservices deployed through Kubernetes and Docker-based infrastructure.

Tech stack: Java, Spring Boot, Spring Security, PostgreSQL, MongoDB, Docker, Kubernetes.
